# Security Policy

## Scope

Resume Studio is a local-only application. It listens on `127.0.0.1` by default and stores resume data in the current browser profile. The project does not provide a hosted service or accept resume data remotely.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting for the repository, or contact the repository maintainer privately with:

- a description of the issue;
- affected versions or files;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Do not include real personal resumes, phone numbers, email addresses, or exported backups in a report. Use synthetic data.

## Supported Versions

Only the latest released version and the default branch are expected to receive security fixes while the project is pre-1.0.
